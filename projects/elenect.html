How might we translate classic board mechanics into a browser-based system? Developing a two-player board-based mechanism using JavaScript.

Overview

Elenect is a two-player, board-based web game developed using Javascript, HTML, and CSS.

The project reimagines a board-based game that connects all the dots as two-player implementation. The game is progressed by each players placing the tokens on the grid, which must be connected to the previous token. Each move can strategically block the opponent's path, creating a simple yet competitive logic dynamic.

Within the minimal interface, the thematic contrast of Fire vs Water was introducted to bring narrative character. The concept influenced the visual palette of contrasting colours, iconography and thematic phrases to make the game more engaging.

RULES AND SYSTEM LOGIC Core mechanics (dotconnect.js) enables the positioning of tokens by checking the availability of adjacent cells.
TWO-PLAYER IMPLEMENTATION The game logic were implemented with visual assets in main.js for two-players play.
  • Alternating turns: each player making one move at a time
  • Detecting the win and lose
  • Total scoring board and repetition of whole process
TESTING AND DOCUMENTATION Conducted Mocha testing to validate the core logic and boundary conditions. Also, lightweight API documentation was written to outline functions and variables.
