How might we simplify group scheduling without endless back-and-forth? Designing a calendar that thinks socially, not individually.

Overview

Group meetups often begin with message overload: endless back-and-forths to find one shared time. Namo reimagines this process by developing a shared calendar mobile application that simplifies group scheduling and event recording.

I joined the project from the early MVP stage, contributing across branding, UX flow, and full mobile interface design. The initial version focused on basic record and shared calendar features, later expanding to include friend lists, improved scheduling logic, and activity blocks.

Problem

Fragmented Scheduling Habits
Calendar schedules and diary records were disconnected, harder to recall the memory.
Overloaded Communication
Group scheduling required repetitive messages and manual coordination.
Lack of Shared Record
Once a gathering ended, the record easily lose a track, losing valuable context and memories.

Process

Designed a complete flow architecture for mobile group scheduling. The flow ensures users to access key features (schedules, groups) in intuitive and consistent hierarchy.

Led the creation of visual identity including logo, colour palette and character assets for in-app and marketing materials. The design embodies the organised yet playful spirit of Namo.

Built and maintained a Figma design system using components and variables, ensuring visual and interaction consistency across the app.
